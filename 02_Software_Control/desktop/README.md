# 电机桌面控制台

首版为可运行的本地交互演示，使用 Python 标准库 Tkinter，无需安装第三方包。
**本版没有串口适配器，不会连接或控制真实电机。现有 F407 固件未修改。**

## 启动

安装带 Tkinter 的 Python 3.10 或更新版本，双击 [启动电机控制台.bat](./启动电机控制台.bat)。也可在工程根目录运行：

```powershell
python -m desktop.app
```

先点击「连接演示设备」，再点击「使能电机」。连接不自动使能、不自动运动。

## 功能

| 控件 | 行为 |
|---|---|
| 单步角度 + 正转 / 反转一步 | 每次鼠标点击执行一次；正转增加角度，反转减少角度；运行中不排队 |
| 目标角度 | 相对当前坐标零点的绝对累计角度，可为负数、可跨圈 |
| 复位 · 返回 0° | 按定位转速返回坐标零点，不执行机械寻零 |
| 设当前位置为零点 | 停止时确认后更改坐标，不转动电机 |
| 定位转速 | 用于点动、指定角度和返回零点；整数 1～3000 RPM |
| 连续旋转 | 先选择方向，单独设置转速和最长时间，再解锁并启动 |
| 连续旋转保护锁 | 解锁只用于一次启动；修改方向/转速/时间、切换模式、停止、断开或失能后重新上锁 |
| 最长运行时间 | 默认 10 秒，可设 0.1～60 秒；模拟器到时停止 |
| 默认转速 | 启动时读取当前 [main.c](../Core/Src/main.c) 的 `APP_JOG_RPM`，当前为 5 RPM；两个模式独立设置 |
| 电机信息 | 显示模拟累计角度、目标、转速、使能、运行状态、倒计时及零点来源 |
| 停止 / Esc | 始终可用；演示中立即停止，实机软件停止仍需通信和反馈确认 |
| 操作日志 | 记录操作、拒绝原因和模拟到位，保留最近约 300 条 |

默认单步角度是界面初值 **1°**，不表示固件的 1 输入脉冲等于 1°。修改输入只影响下次命令，不改变正在运行的命令。断开重连保留模拟坐标，但恢复未使能、已上锁状态。

电压、电流没有实测值时显示「—」，不会生成虚假读数。演示中的零点和位置均为模拟值。

## 后续接入实机

[controller.py](./controller.py) 将界面与设备通信分开，`MotorBackend` 定义角度定位、连续旋转、反馈、使能、停止和坐标零点的边界，当前由 `DemoBackend` 实现。先接入 F407 串口后，再切换 USB 转 RS485 可保留界面。

当前固件只配置了 USART2 PA2/PA3 + PG8 作为电机 RS485 通信；ST-Link 虚拟串口接到 MCU 的引脚尚未确认，不能从固件配置推断实际接线。接入时需要：

1. 按实际接线增加独立的电脑串口入口，与现有 `motor_app` 共用一个事务调度入口。
2. 根据实际电机步距角、细分和输入缩放确定角度与输入脉冲换算，并报告量化后的可执行角度。反馈角度继续使用 Emm 的 65536 单位/圈，不与输入脉冲混用。
3. 明确驱动坐标零点与用户坐标偏移；机械寻零需要另行确认传感器/回零模式。首版「复位」不宣称已机械回零。
4. 当前业务层没有连续速度模式，需依据厂家实际固件协议增加速度命令、状态管理、停止确认及 **F407 端超时停止**。电脑端倒计时无法替代设备侧保护。
5. 真实信息展示使用实际回复，并区分命令已接受、运动中、已到位、停止已接受与静止已确认；通信丢失时显示反馈无效，不继续展示为实时值。

本版未实现真实串口发送，也未发送使能、回零、校准或配置写入命令。

## 验证

```powershell
python -m unittest discover -s desktop/tests -v
```

测试覆盖单次运动、不排队、正反转/绝对角度/零点、连续保护锁、到时停止、断开和失能，以及非法数字的拒绝。软件测试不等于实机验证。
