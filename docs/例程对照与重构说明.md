## 对照结论

| 例程行为 | 本工程处理 |
|---|---|
| 上电HAL_Delay(500) | 保留500ms准备时间，改为非阻塞BOOT_WAIT，上电无指令 |
| USART1/PA9/PA10、DMA2 | 保留现有USART2/PA2/PA3和DMA1，避免破坏硬件连接 |
| HSE/168MHz系统时钟 | 保留现有时钟，未盲目复制生成配置 |
| FD 13字节位置命令 | 字节布局一致，提取到独立emm_v5编码器 |
| 示例relative=0、acc=0 | 默认按键和Watch参数改为0、0，恢复例程运动语义 |
| 示例1000RPM/32000脉冲，自动运行 | 不复制上电运动；默认显式按键80脉冲、5RPM |
| F3 AB使能控制 | 新增公开接口；显式运动请求中先使能、确认、读回状态 |
| FE 98立即停止 | 新增公开接口和K0优先软件停止请求 |
| while(rxFrameFlag==false)无期限等待 | 单事务、100ms响应期限、错误/拒绝码和失败阶段 |
| static cmd保持DMA源缓冲 | 驱动复制到固定TX缓冲，发送期间不能覆盖 |
| 36符号+32位、65536单位/圈 | 保留相同解析，无符号幅值转int64后加符号 |
| 模板注释vel上限5000RPM | 当前X42S手册保守限制3000RPM；未把注释当成固件能力证明 |
| 模板选项状态简图 | 本台实机5字节回复为准，保留16位选项和高位 |

原位置帧的布局经对照并未发现错误。此前不能转动不能据此认定由编码格式导致。
这次重点修正结构、显式使能流程、例程默认参数和结果可观测性，不承诺已解决所有实机原因。

## 软件改动

- 新增`Core/BSP/emm_v5.c/h`：纯C指令编码，受检长度与宽参数，大端序，固定6B。
- 新增`Core/BSP/motor_app.c/h`：统一应用所有权、明确阶段、启动延迟、使能/运动/停止、独立请求和执行结果。
- 重构`Core/BSP/zdt_x42s.c/h`：移出准备状态机，加入使能与停止事务，白名单帧长度和原始发送记录，保留运动证据。
- 重构`Core/Src/main.c`：统一按键和Watch路由，K0停止、K1/K2运动，50ms快照；版本旧Watch仍保留。
- `CMakeLists.txt`：加入两个新增模块。
- 按键消抖及STEP/DIR模块保留；阻塞式KEY_Proc不进入主循环。
- 重写`tests/test_communication.c`和测试运行器；保留按键测试；新增原例程编码对比脚本。
- 重写当前调试说明，移除已过时的补丁历史。

## 接下来实机验证

1. 新固件下载后静置500ms，确认没有上电运动、使能或自动查询。
2. 用Watch request=1查询版本，核对app.stage=DONE、app.result=OK。
3. 确认机械行程和实际细分后按一次K1，观察OPTIONS→ENABLE→STATUS→BASELINE→MOVE_ACK→MONITOR。
4. 核对`last_tx/move_frame/move_reply`；02只是接收，实际变化看position_delta，到位看motion/arrived。
5. 在可控机械条件下测试K0；验证旧查询回复不会完成FE事务，STOP_ACCEPTED不等于实测静止。
6. 若不转，记录有效的目标/实际位置、总线电压、相电流和故障阶段，再核对校准及电机侧限制参数。
7. 故意丢失回复验证超时锁定、无自动运动重试；处理后显式恢复，不能靠反复按键绕过。

本次仅完成源码、编码和模拟验证；未操作ST-LINK、未烧录、未自动启动实际电机。
